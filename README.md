# Seoul Bike Rental Demand Forecasting

Advanced deep learning models for accurate bike rental demand prediction using temporal and meteorological features.

## About

This project develops and compares multiple advanced deep learning architectures to forecast hourly bike rental demand in Seoul. The goal is to improve forecasting accuracy through sophisticated temporal modeling, feature engineering, and ensemble techniques. The models leverage weather data, temporal patterns, and historical demand information to predict bike rental counts.


**Multiple Deep Learning Models**:
- Temporal Convolutional Networks (CNN)
- Convolutional LSTM (ConvLSTM)
- LSTM with GRU and Attention mechanism
- Transformer-based architecture
- LSTM + Random Forest hybrid model


**Comprehensive Evaluation**:
- Multiple regression metrics (MAE, RMSE, R², MAPE)
- Chronological train-test split to avoid data leakage
- Model comparison visualizations
- Performance analysis across different time periods


- **`Comparison_of_different_models_final.ipynb`**: Final model performance comparison
